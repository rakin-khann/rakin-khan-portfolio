# Rakin Khan — 3D Personal Portfolio

A React + Vite portfolio foundation with a responsive editorial layout and a lightweight interactive Three.js hero scene.

## Stack
- React 19
- Vite 8
- Three.js with React Three Fiber and Drei
- Lucide React icons

## Local development
Requires Node.js 22.12+ and npm.

```bash
npm install
npm run dev
```

## Environment
Supabase integration will be added in the next phase. Never commit secret keys or service-role credentials. Browser-side configuration must use only the Supabase publishable key.
